# IT Projects

This repository contains five beginner→advanced learning project scaffolds spanning IT, Computer Science, and Cybersecurity. Each project has a short README and starter code to help you get started.

Projects:

1. sys-admin-scripts — Handy bash and Python scripts for backups, user reporting, and simple network checks. (Beginner / IT)
2. algorithms-python — Clean implementations of common algorithms & data structures with tests and exercises. (Beginner → Intermediate / CS)
3. fastapi-template — Production-ready FastAPI REST template with Dockerfile and basic auth placeholder. (Intermediate / CS/IT)
4. vuln-web-lab — Docker Compose scaffold to run OWASP Juice Shop with guided safe lab exercises. (Intermediate / Cybersecurity)
5. ml-from-scratch — From-scratch ML algorithms and notebooks (linear/logistic regression, gradient descent). (Advanced / CS)

See each project's folder for details and usage instructions.
