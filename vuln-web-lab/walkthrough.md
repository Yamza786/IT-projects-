# Vulnerable Web Lab Walkthrough

This document lists safe exercises to practice OWASP Top 10 techniques against the Juice Shop instance.

Examples:

- A1 Injection: find an input that reflects data and attempt SQLi-related payloads in a controlled manner.
- A2 Broken Authentication: explore password reset flows and reason about secure design.
- A3 Sensitive Data Exposure: inspect what data is stored and how to protect it.

Always practice only on local instances you control. Do not scan or attack systems you do not own.
