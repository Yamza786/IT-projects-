## Interactive showcase

Serve the repository root with any static HTTP server, then open `/portfolio-command-center/`. Search matches project names, summaries, categories, collections, and technology stacks; category buttons narrow the view. Each card links to the corresponding project README. Project metadata is maintained in [projects.json](projects.json).

This catalog describes repository contents; it does not claim that projects are deployed or production-ready. Preserve unique IDs and repository-relative README paths when updating the data.
