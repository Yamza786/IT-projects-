# IT/CS Portfolio Command Center

A compact static dashboard for browsing the repository's projects, grouped by area and linked directly to each project README. Project metadata is maintained in `projects.json`; the frontend is framework-free and works offline.

## Run

Open `index.html` directly, or serve the repository root with `python -m http.server 8000` and visit `/portfolio-command-center/`. Use the search box and category filters to find projects. This showcase is generated from the curated metadata file and does not claim projects are deployed or production-ready.
