# Making the repository public

To make the repository public via the web UI:
1. Go to: https://github.com/Yamza786/IT-projects-
2. Click Settings → General → Change repository visibility → Make public
3. Confirm by typing the repo name when prompted.

To make the repository public via GitHub CLI:

gh repo edit Yamza786/IT-projects- --visibility public

Note: After making the repo public, the PRs and workflows will be visible to others and can be used in your portfolio.
