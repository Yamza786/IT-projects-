# algorithms-python

Implementations and exercises for common algorithms and data structures in Python.

Structure:
- `algorithms/` — implementations
- `exercises/` — practice prompts and tests in `tests/`

Run tests: python -m pytest

## Linear regression demo

The gradient descent example fits a line to a small, deterministic data set
and saves an SVG plot beside the script. Install NumPy, then run:

```sh
python examples/linear_regression_demo.py
```

The generated prediction plot is `examples/linear_regression_predictions.svg`.
